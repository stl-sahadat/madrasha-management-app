# Module 09: Smart ID Card Generator (স্মার্ট আইডি কার্ড জেনারেটর)

## Overview
Dual-side, 300 DPI high-definition printable ID card generator for students and teachers.

## Specifications
- Standard CR-80 card dimensions (85.6mm x 53.98mm).
- High-resolution student photo frame with rounded borders.
- Institution circular logo, blood group badge, student registration, and emergency contact.
- Backside with madrasa terms, rules, and principal's signature.
- Instant batch printing via browser `@media print`.
