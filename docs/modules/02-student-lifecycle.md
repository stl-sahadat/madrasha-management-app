# Module 02: Student Lifecycle (ছাত্র-ছাত্রী ব্যবস্থাপনা)

## Overview
Comprehensive student admissions, enrollment, 12-month payment matrices, and disciplinary records.

## Features
- **Admission & Registration**: Automated registration generation, guardian contacts, previous education background.
- **12-Month Matrix**: Real-time month-by-month fee collection tracker (January through December) with Paid, Due, and Partial status badges.
- **Khuraki (Mess) Register**: Boarding student food fee tracking and kitchen billing.
- **Blood Group Directory**: Emergency donor search by blood group across all students.
- **Guardian Mobile Directory**: Instant batch contact lookup for administrative communications.
